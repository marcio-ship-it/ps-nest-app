# PS Nest — browser version

Sheet nesting for the router, running entirely in your browser: open the link, load an example or
type your parts, press **Nest**, download the DXF cut files, layout sheet and 1:1 print PDF.

Nothing is uploaded anywhere — the Python engine runs on your own computer or phone (Python
compiled to WebAssembly via [Pyodide](https://pyodide.org)). The first visit downloads about 15 MB;
later visits are quick. Uploaded artwork and outlines live only in that browser tab.

Built from the `ps-nest` repository by `scripts/build-web.py` — do not edit these files by hand.
