About the Trello import
Pulls the artwork attached to the card - every PDF, loose or inside a zip - and makes one part per file: size and shape from its CutContour line, quantity from the file name (_575x560___3x.pdf). The card text (title, description, checklists) is read as well and checked against the files: sizes with no file, files with no line, quantities that differ. A card without files gives rectangles from the text only, so there is nothing to print. Check every row before nesting.

About W, H, Turn and shapes
W is the size along the sheet length, H along the sheet width, as the artwork is drawn. Untick Turn for parts with a grain or a print that must stay upright. Shapes: circle / polygon / star use W as the diameter across points; Text cuts one part per letter at height H (Arial Bold unless chosen); Cut path uses an uploaded DXF / SVG outline, scaled to W; CutContour takes the shape from the pink cut line in the part's artwork PDF (W and H fill in by themselves).

How the artwork is placed
Assign a file to a part in the table. The print PDF places it 1:1 on each sheet at the part's position, turned with the part, scaled to the part plus bleed if the page size differs.

Print & cut. Drop the PDF and its part row is added for you. If the PDF carries a cut line in the CutContour spot colour (the pink line Flexi, Onyx, Caldera, Summa and Roland use), the part takes its size and real shape from that line: W, H and Shape are filled in and locked. After nesting, Print files is one PDF per sheet with the artwork and the cut line removed, and Cut files is one PDF per sheet with only the cut lines, on the same page so they register; the files pair up by number and carry the final size (1_print_2440x1220.pdf with 1_cut_2440x1220.pdf); with sheet frame ticked both also carry the same hairline rectangle on the sheet edge. Bleed wider than half the gap is trimmed in the print PDF so parts cannot print over each other. The line is used exactly as drawn: it must be a closed shape, and PS Nest never draws, closes or offsets one.

How cut paths become parts
Every closed path becomes a part; holes and islands stay with their outer path. "Add parts" puts one row per path in the table with Shape = Cut path. Open paths, text and dimension layers are skipped and reported.

How to use

  1. Pick the material and the machine that cuts it (the sheet or roll frame, margins, gap and machine file follow), or load an example.
  2. Type the parts: finished size, quantity, whether they may be turned.
  3. Check the rules. Defaults come from published ACM and CNC-nesting guidance (see "Where each default comes from"); bleed and smallest offcut are shop judgement.
  4. Nest. The program tries hundreds of layouts and keeps the one with the fewest sheets, then the largest clean offcut.
  5. Download the DXF cut files (one per sheet), the print files (one per sheet, 1:1) and the layout sheet for the operator. For print & cut artwork (CutContour line in the PDF) also download the cut files - numbered to pair with the print files.
