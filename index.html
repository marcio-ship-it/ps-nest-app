Guide to shapes, print & cut

W is the size along the sheet length, H along the sheet width, as the artwork is drawn. Shapes (this column shows while Settings is open): circle / polygon / star use W as the diameter across points; Text cuts one part per letter at height H; Cut path uses an uploaded DXF / SVG outline, scaled to W; CutContour takes the shape from the pink cut line in the part's artwork PDF (W and H fill in by themselves).

Print & cut. If the PDF carries a cut line in the CutContour spot colour (the pink line Flexi, Onyx, Caldera, Summa and Roland use), the part takes its size and real shape from that line. After nesting, Print files is one PDF per sheet with the artwork and the cut line removed, and Cut files is one PDF per sheet with only the cut lines, on the same page so they register; the files pair up by number and carry the final size (1_print_2440x1220.pdf with 1_cut_2440x1220.pdf). Bleed wider than half the gap is trimmed in the print PDF so parts cannot print over each other. The line is used exactly as drawn: it must be a closed shape, and PS Nest never draws, closes or offsets it. A PDF without a cut line is placed as a rectangle at its page size.

Trello. Fetch pulls every PDF attached to the card, loose or inside a zip, and makes one part per file: size and shape from its CutContour line, quantity from the file name (_575x560___3x.pdf). The card text is read as well and checked against the files. Check every row before nesting.

Quick start guide

Connect to NAS

Use the NAS address and your authorised account. This connection reads finished-art PDFs; it does not change files or permissions on the NAS.

HTTPS is preferred. An HTTP Tailscale address requires Tailscale to be connected and the NAS to appear as a peer. Other HTTP addresses are refused.

Enter your password. It is never included in the app download.

Job folder

The app searches this folder for the PL number, then reads PDFs inside the job's FA folders.

Without this option, the connection lasts until PS Nest closes.

How to use

  1. Material. Pick what the job is printed on or cut from. The printer, the cutter, the sheet size and the machine file follow from it.
  2. Parts. Drop the artwork PDFs, one per part, at final size with the pink CutContour cut line. Each file becomes a part: check the quantity. No artwork? Add a part by size.
  3. Nest. Press Nest. The sheets appear on the right with the numbers and the downloads: everything in one zip, or the print files, cut files, router DXF and layout sheet on their own.
  4. Settings (below the Nest button) holds the printer, margins, gap, bleed, nesting mode and the rest. The defaults are the shop's; you rarely need to open it.
