PS Nest

Sheet nesting for the router. Fewest sheets, biggest clean offcut, all rules respected.

Job

Reads the card title, description and checklists and lists every line with a W x H. Check every row before nesting; the parser is plain.

Parts

NameShapeW mmH mmQtyTurnArtwork
W is the size along the sheet length, H along the sheet width, as the artwork is drawn. Untick Turn for parts with a grain or a print that must stay upright. Shapes: circle / polygon / star use W as the diameter across points; Text cuts one part per letter at height H (Arial Bold unless chosen); Cut path uses an uploaded DXF / SVG outline, scaled to W.

Where each default comes from

Artwork (PDF, one page, at final size)

Drop PDF files here or click to choose
Assign a file to a part in the table. The print PDF places it 1:1 on each sheet at the part's position, turned with the part, scaled to the part plus bleed if the page size differs.

Cut paths (DXF or SVG outlines, mm)

Drop DXF / SVG files here or click to choose
Every closed path becomes a part; holes and islands stay with their outer path. "Add parts" puts one row per path in the table with Shape = Cut path. Open paths, text and dimension layers are skipped and reported.

How to use

  1. Pick the product and sheet, or load an example.
  2. Type the parts: finished size, quantity, whether they may be turned.
  3. Check the rules. Defaults come from published ACM and CNC-nesting guidance (see "Where each default comes from"); bleed and smallest offcut are shop judgement.
  4. Nest. The program tries hundreds of layouts and keeps the one with the fewest sheets, then the largest clean offcut.
  5. Download the DXF cut files (one per sheet), the 1:1 print PDF and the layout sheet for the operator.
